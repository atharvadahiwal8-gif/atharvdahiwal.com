Put it online and connect www.atharvdahiwal.com
  1. Upload this whole folder to a static host: Netlify (drag and drop the folder at app.netlify.com/drop),
     Cloudflare Pages, Vercel, or GitHub Pages.
  2. In the host's dashboard, add the custom domain www.atharvdahiwal.com.
  3. At your domain registrar, add the DNS record the host shows you (usually a CNAME for www).
  4. Wait for DNS to update, then turn on HTTPS in the host's settings.
